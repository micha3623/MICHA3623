# MICHA3623 — Official Website

**Smart Shopping. Better Living.**

A responsive, editorial-style storefront concept for **MICHA3623**, an emerging E-commerce & Retail brand.

## Features
- Black Platinum brand palette (`#171717`, `#BFC7D2`, `#FFFFFF`)
- Responsive desktop, tablet and mobile layouts
- Lifestyle collections and editorial imagery
- Searchable, filterable **demonstration** product catalog
- Browser-local saved favorites (no account required)
- Brand story and GitHub contact link
- Semantic HTML, accessible navigation, reduced-motion support

## Run locally
Open `index.html` in a browser. No build step or dependencies are required. Internet access is needed for Google Fonts and externally hosted Unsplash images.

## Publish on GitHub Pages
Upload the **contents** of this folder to the root of your `micha3623-website` repository. In GitHub, choose **Settings → Pages → Deploy from a branch → main / (root)**.

## Project structure
```
index.html
css/style.css
js/script.js
README.md
```

## Important
This is a **brand demonstration website**, not an active online store. Catalog entries are editorial concepts, not real products for sale. There is no inventory, cart checkout, payment processing, order fulfillment, or operational contact form. Favorites are stored only in the visitor's browser. Product imagery comes from Unsplash-hosted URLs and is subject to third-party terms and availability. Replace demonstration content and external photos with properly licensed brand assets before commercial launch.
